HOW IT WORKS

    
The same record as the registry.

    

      
Pinned to a commit
The Hub API is read at the model's current commit sha with our server key, which never reaches your browser. LFS and Xet files use the Hub's LFS SHA-256. Small files are downloaded at that commit and hashed.

      
One content hash
sha256("model-v1\0" + canonicalJson(hfRepo, revisionSha, files, license, provenance)). This is the exact preimage of artifact-registry/src/hash.mjs, recomputed in your browser before you sign.

      
Frozen on mint
The Core asset's update authority is an index address that nobody can sign for, so its name, URI and attributes can never change. You own it and can transfer or burn it. zk attestation is still pending.
