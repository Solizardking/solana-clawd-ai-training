VERIFICATION

    
Typed verdicts from JEV.

    

      
Deterministic first
No inference spent until the bundle passes a precheck: frontmatter present, no credentials or private keys, no curl | sh. Bundles that contain secrets are refused and never stored.

      
Then JEV decides
typesafe/jev-1.13 answers five typed probability questions (secrets, unconfirmed funds, remote code, instruction override, honest description). Every check has to score at least 0.90 to verify. Any check at 0.10 or below rejects. Anything in between stays unverified.

      
Fail closed
If JEV is unavailable the skill is unverified, never verified. The badge shows only when this server holds the typed verdict whose hash matches the asset's onchain jevVerdict attribute.
